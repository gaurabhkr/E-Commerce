_E Commerce_ is an __SpringBoot__ based  Application. It was developed during learning Spring and _**NSDC HCL Internship**_ . 

<br>

It is an *Project* which I had to submit in  _**NSDC HCL Tech Internship**_ in which we assigned to develop an Full Stack Ecommerce Application using **Java Stack Technology**.

<br>

This Project aims to _**deliver Backend Services not much Frontend Service**_ *(I didn't know about the Frontend Tech during development of project which makes this *Application less Responsive*)*.
We had to develop an Application as per **Design Documents** _like ER Diagram, Data Flow Diagram_ and submit it. 
<br><br>

- It used *SpringBoot* and Spring Serivces *like* *Spring MVC, Spring JPA* <br>

- All **User Data** is Stored on PostgreSQL Cloud Storage<br> 

- It features mainly _**Backend**_ services of Application<br>  

- _**JSP**_ and _**CSS**_ is used for Frontend View of Application

- I used my own Login System for User( _I don't know about Spring Security during development_ ) 

- It has Simple **Frontend** , I mainly worked on **Backend Services** of Application.

<br> 


>This Project is developed when I was in my 2nd Year and learning Java Stack which make it as my *First Spring Based Application*.
